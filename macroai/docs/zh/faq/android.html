为什么需要开启"无障碍服务"权限？不开会怎样？Android

无障碍服务（Accessibility Service）是 MacroAI Android 版的核心权限，用于：

  • 模拟触摸操作 — 通过 dispatchGesture 注入点击/滑动手势到系统
  • 悬浮窗编辑器 — 在其他应用上方显示编辑界面

不开启的后果：脚本无法执行任何点击/滑动操作，相当于"有脑子但没有手"。

开启方法：

  1. 进入手机 设置 → 无障碍（或"辅助功能"）
  2. 找到"已下载的应用"或"已安装的服务"
  3. 找到 MacroAI，开启开关
  4. 系统会弹出安全提示，点"确定"

不同品牌手机路径不同（华为/小米/OPPO/vivo 各有差异），MacroAI 会尝试自动跳转到对应设置页。

为什么需要"悬浮窗"权限？Android

MacroAI Android 版的编辑器和运行控制都是悬浮在其他应用上方的（因为你操作的目标是其他应用/游戏，MacroAI 不能占满屏幕）。

悬浮窗权限让 MacroAI 可以：

  • 在游戏/应用上方显示编辑气泡和节点配置面板
  • 显示运行控制气泡（播放/暂停/停止）
  • 显示录制覆盖层

不开启的后果：无法在其他应用上方显示任何界面，编辑器和运行控制都不可用。

开启方法：设置 → 应用管理 → MacroAI → 悬浮窗（或"显示在其他应用上方"）→ 允许。

屏幕录制授权弹窗能跳过吗？每次都弹好烦。Android

不能跳过，这是 Android 系统强制要求。

MacroAI 需要截取屏幕画面来做图像识别、OCR、颜色检测等操作。Android 系统规定，任何应用截取屏幕都必须经过用户明确授权（MediaProjection API），且每次启动服务时都要重新授权。

这是系统安全机制，MacroAI 无法绕过。

好消息：

  • 弹窗只在启动运行/编辑时出现一次，不会反复弹
  • 部分 Android 11+ 设备支持"记住选择"，勾选后不再弹出
  • 如果你只是导入运行别人的脚本（不需要截图功能），某些场景可以不授权
为什么我的手机开启无障碍服务后过一会儿就自动关闭了？Android

这是国产安卓手机（华为/小米/OPPO/vivo/荣耀）的后台管理策略导致的——系统为了省电会自动"杀死"后台服务。

解决办法（按品牌）：

  • 通用：设置 → 电池 → 找到 MacroAI → 设为"不限制"/"无限制"
  • 小米：设置 → 应用设置 → 应用管理 → MacroAI → 省电策略 → 无限制；同时锁定最近任务（下拉锁定）
  • 华为/荣耀：设置 → 电池 → 启动管理 → MacroAI → 关闭"自动管理"，手动开启所有开关
  • OPPO/vivo：设置 → 电池 → 后台耗电管理 → MacroAI → 允许后台运行

额外建议：在最近任务/多任务界面把 MacroAI "锁定"（通常是下拉或长按加锁），防止被一键清理。

安卓版的编辑器在哪里？怎么打开？Android

Android 版的编辑器不是一个独立界面，而是以悬浮气泡的形式显示在其他应用上方。

打开方式：

  1. 在 MacroAI 主界面（项目列表）中选择一个项目
  2. 点击"编辑"按钮
  3. MacroAI 会最小化到后台，屏幕上出现一个编辑气泡
  4. 点击气泡展开编辑菜单（添加节点、配置、运行等）

为什么这样设计？因为你需要一边看着目标应用/游戏的画面，一边编辑脚本。如果编辑器占满屏幕，你就看不到要操作的目标了。

气泡可以拖动位置，不用的时候可以收起到很小，不遮挡画面。

安卓版支持哪些节点类型？和 Windows 版一样吗？Android

大部分核心节点两端都支持，但有差异：

两端都支持的：

  • 查找图像（含点击）、颜色检测、OCR 识别/比对
  • 等待变化、等待条块变化
  • 鼠标点击（触摸点击）、鼠标移动、鼠标拖拽
  • 等待、循环、条件判断、设置变量、日志
  • 调用函数、调用录制宏

有差异的：

  • 按键/输入文本：Windows 用虚拟键码，Android 用无障碍服务输入，部分特殊键不支持
  • 后台输入：Windows 有后台/前台模式切换，Android 统一通过无障碍服务注入（天然"后台"）
  • 自定义代码：两端都支持 Lua，但可用的 API 略有差异

导入不兼容的节点时会被自动跳过，不会导致整个脚本失败。
