Pro 功能与授权

免费版和 Pro 版有什么区别？通用

MacroAI 基础功能永久免费，无广告。Pro 版解锁进阶能力：

免费功能：

  • 节点编辑器（图像查找、鼠标点击、等待、循环、条件、变量、日志等）
  • 颜色检测
  • 录制与回放、函数、变量
  • 运行/调试、日志、浮动面板
  • 项目导入/导出

Pro 功能：

  • OCR 文字识别、OCR 比对
  • 等待变化、等待条块变化
  • 播放音乐、自定义代码（Lua）
  • 坐标策略覆盖（节点级 transform_policy）

具体哪些功能需要 Pro，在界面中会以 🔒 标记显示。

Pro 过期后已有的脚本还能运行吗？通用

可以。Pro 过期后的限制是：

  • ❌ 不能新增 Pro 节点（按钮变灰，提示"已过期"）
  • ❌ 已有的 Pro 节点不可编辑（双击会提示"Pro 节点已过期，不可编辑"）
  • ✅ 已有的脚本（包含 Pro 节点）仍然可以正常运行

简单说：Pro 限制的是"创建和编辑"，不影响"运行"。你的脚本不会因为 Pro 过期就报废。

哪些节点/功能是 Pro 专属的？通用

在节点面板中，Pro 节点会显示 🔒 标记。当前 Pro 专属的主要有：

  • OCR 识别、OCR 比对（文字识别相关）
  • 等待变化、等待条块变化（屏幕监控相关）
  • 播放音乐、自定义代码（Lua 脚本）
  • 坐标策略覆盖（节点级 transform_policy 设置）

大部分日常使用的节点（图像查找、颜色检测、点击、等待、循环、条件等）都是免费的。

如果你不确定某个功能是否需要 Pro，直接点击尝试——需要 Pro 时会弹出提示，不会误操作。

其他常见问题

项目数据保存在哪里？换了电脑怎么迁移？通用

保存位置：所有项目保存在你首次使用时选择的"工作目录"中。每个项目是一个文件夹，包含 task.json（脚本数据）、resources/（图片等资源）、macros/（录制的宏）。

迁移方法：

  • 方法一（推荐）：在 MacroAI 中导出项目为 .macroai 文件 → 拷贝到新电脑 → 导入
  • 方法二：直接拷贝整个工作目录到新电脑 → 在新电脑 MacroAI 中选择同一目录

Android 版：项目数据在应用私有目录中，通过导出 .macroai 文件迁移最方便。

自动保存是怎么工作的？会不会丢失修改？通用

MacroAI 有自动保存机制，你不需要频繁手动保存：

  • 任何修改（添加节点、改配置、改变量等）后，5 秒内无新操作就自动保存
  • 状态栏会显示"5秒后自动保存..."提示
  • 切换项目、运行脚本、导出、退出前都会自动保存

会丢失修改的情况：

  • 修改后 5 秒内程序崩溃/电脑断电（极罕见）
  • 磁盘写入失败（如磁盘满了）

想立即保存可以按 Ctrl+S。正常使用下不需要担心数据丢失。

支持多显示器吗？脚本能在副屏运行吗？Windows

支持。MacroAI 可以操作任何显示器上的内容。

使用方法：

  • 创建设计区域时，框选副屏上的目标窗口即可
  • 截图、图像查找、鼠标点击都基于屏幕绝对坐标，不受"哪个是主屏"限制

注意事项：

  • 如果两个显示器 DPI 缩放不同（如主屏 125%、副屏 100%），需要注意坐标空间一致性
  • 建议两个显示器使用相同的 DPI 缩放比例
  • 运行脚本时目标窗口不要跨屏移动
脚本能定时执行吗？通用

MacroAI 目前不支持定时执行，后续版本会支持该功能。

替代方案：

  • 在脚本内部用"无限循环 + 等待"实现简单定时（如每隔 30 分钟执行一次）
  • Windows 用户可以用系统的任务计划程序（Task Scheduler）定时启动 MacroAI

目前也不支持命令行直接运行脚本，MacroAI 启动后需要在界面中手动操作运行。

如何设置开机自启动/后台常驻？Windows

开机自启动：

  • 方法一：把 MacroAI 的快捷方式放入启动文件夹（Win+R → 输入 shell:startup → 回车 → 放入快捷方式）
  • 方法二：在 Windows 任务计划程序中创建"登录时"触发的任务

后台常驻（最小化到托盘）：

  • MacroAI 支持系统托盘图标，关闭窗口时会最小化到托盘而非退出
  • 右键托盘图标可以快速打开主窗口或退出程序

配合 Windows 任务计划 + 脚本内无限循环，可以实现"开机后自动在后台持续运行脚本"。
