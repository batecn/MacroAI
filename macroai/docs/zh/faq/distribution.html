分发与导入导出

← 返回所有分类
如何把做好的脚本分享给别人使用？通用

MacroAI 支持将项目导出为单个文件，发给别人直接导入使用：

  1. 在 MacroAI 中打开你的项目
  2. 点击菜单 项目 → 导出项目
  3. 选择保存位置，生成 .macroai 文件
  4. 通过微信/QQ/邮件等方式发送给对方

对方收到后：

  • Windows：双击 .macroai 文件自动打开 MacroAI 并导入（已安装的情况下）
  • 或者在 MacroAI 中点击 项目 → 导入，选择文件
  • Android：用 MacroAI 打开文件，自动导入并进入运行界面

导出文件包含所有节点、图片、变量、函数等完整项目数据。

什么是"分发包"？和普通导出有什么区别？通用

导出时有两种选择：

  • 普通导出 — 明文包，导入后可以看到和编辑所有节点。适合：备份、团队协作、自己换电脑。
  • 分发包（加密导出）— 脚本内容加密，导入后只能运行，不能查看/编辑节点。适合：分发给最终用户、保护设计成果。

分发包的特点：

  • 导入后自动进入运行模式，设计模式入口灰色不可点击
  • 使用者看不到节点编辑器、代码等设计内容
  • 使用者只能：校准区域、填写个性化配置、运行/停止
  • 加密保护，无法通过解压文件还原脚本

导出时勾选"分发包"选项即可生成加密包。

导入 .macroai 文件后为什么看不到节点编辑器？通用

这是因为你导入的是一个分发包（加密包）。分发包的设计目的就是"只让使用者运行，不让查看/修改脚本"。

导入分发包后：

  • 自动切换到运行模式
  • 设计模式入口变灰，无法切换
  • 你只能看到：项目信息、区域校准、个性化配置、运行按钮

这是正常行为，不是 bug。如果你需要编辑脚本，需要找设计者要普通导出包（非加密），或者让设计者给你源项目。

使用者导入脚本后需要做哪些配置才能运行？通用

导入后切换到运行模式，通常需要：

  1. 校准运行区域（如果你的屏幕分辨率/窗口位置和设计者不同）
    • 点击"校准"按钮，框选目标程序在你屏幕上的实际位置
    • 如果设计者用的全屏且你也是同分辨率全屏 → 可跳过
  2. 填写个性化配置（如果设计者定义了用户配置变量）
    • 如：上传你自己的头像图片、输入你的游戏昵称
    • 界面上会显示需要填写的项目
  3. 点击运行

运行模式界面有"配置完整度"提示，告诉你还有哪些配置没完成。

"用户配置变量"是什么？设计者和使用者分别怎么操作？通用

用户配置变量让设计者预留"可自定义的位置"，使用者运行前填入自己的值。

典型场景：脚本中需要点击用户的游戏头像，但每个人的头像不同 → 设计者定义一个"头像"图片变量，使用者运行前截自己的头像。

设计者操作：

  1. 在"用户配置"标签页（Ctrl+9）中定义变量（如：ID=avatar，名称=我的头像，类型=图片）
  2. 在图像查找节点中，通过 ◎ 按钮引用该变量（字段显示 u|avatar）

使用者操作：

  1. 在运行模式界面看到"我的头像"配置项
  2. 点击截图/上传，提供自己的头像图片
  3. 运行时脚本自动使用使用者提供的图片
Windows 和 Android 的项目文件可以互相导入吗？通用

可以。两端使用相同的项目格式和加密协议，.macroai 文件双向兼容。

在 Windows 上制作的脚本可以导出后在 Android 上导入运行，反之亦然。

注意事项：

  • 坐标策略和分辨率适配仍然需要处理（两端屏幕尺寸不同，运行前需校准）
  • 某些节点可能一端支持另一端不支持（导入后不支持的节点会被跳过）
  • Windows 的"按键"节点使用虚拟键码，Android 上可能行为不同
