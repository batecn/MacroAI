MacroAI 隐私政策

生效日期：2026 年 9 月 3 日 | 应用名称：MacroAI（Windows 版 / Android 版，包名 com.sowe.macroai）

一、引言

MacroAI（以下简称"本软件"）尊重并保护用户隐私。本隐私政策说明本软件在运行过程中如何处理您的信息。使用本软件即表示您同意本政策的条款。

二、信息收集

本软件不收集、不上传、不共享任何个人数据。

  • 本软件不会收集您的个人信息、使用习惯或操作记录；
  • 本软件不包含任何遥测、统计分析或广告 SDK；
  • 您创建的脚本、图像模板、节点配置、用户配置等数据均仅存储在您的设备本地，不会上传至任何服务器；
  • 本软件的图像识别（OpenCV 模板匹配）、文字识别（OCR）、颜色识别均在设备端离线完成。

三、网络访问

Windows 版

运行过程中不主动建立任何网络连接。版本更新通过您主动访问官网或发布页面下载安装包完成。

Android 版（Google Play 渠道）

本版本不含任何网络通信功能，不建立任何网络连接。版本更新完全由 Google Play 提供。

Android 版（官网等其他渠道）

仅会定期向我们的服务器（sowe.com）发起版本更新检查请求。该请求仅用于判断是否有新版本，不携带或上传您的任何个人数据、脚本内容或屏幕信息。

四、第三方服务

本软件不集成任何第三方分析、广告或数据收集服务。所使用的开源组件（包括图像处理与文字识别引擎）均以本地库形式运行，不会与外部服务器通信。

五、Android 权限说明

MacroAI Android 版使用以下系统权限。所有权限仅用于实现自动化功能，绝不用于收集个人信息；所有权限均由您在系统中主动授予，可随时撤销，撤销后相关功能停止工作且不留存任何数据处理行为：

  • 无障碍服务（AccessibilityService）：用于执行自动化点击、滑动等手势操作，以及读取界面元素信息；读取的屏幕内容仅用于脚本运行时的本地匹配与判断；
  • 屏幕录制/截图权限（MediaProjection）：仅在脚本需要图像识别、OCR 或取色时使用，用于获取屏幕内容进行本地分析；截图内容仅在内存中临时处理，不会保存、上传或分享给任何第三方；
  • 悬浮窗权限（SYSTEM_ALERT_WINDOW）：用于显示运行气泡、任务面板与节点编辑器等操作界面；
  • 前台服务：用于保持自动化任务与编辑器在后台稳定运行。

六、数据存储与删除

您在使用本软件时产生的所有数据（包括脚本配置、模板图片、用户配置等）均存储在设备本地目录中。由于数据完全存储在本地，数据安全由您自身的系统安全措施保障，我们建议您定期备份重要数据。

您可随时通过卸载本软件或清除应用数据的方式彻底删除全部本地数据；我们无法在远程获取、保留或恢复这些数据。

七、儿童隐私

本软件不面向 13 周岁以下的儿童，我们不会故意收集儿童的个人信息。

八、隐私政策的更新

我们可能会不时更新本隐私政策。更新后的政策将在本页面发布，并更新顶部的生效日期。如果未来本软件引入账号系统、云服务或其他需要收集数据的功能，我们会及时更新本政策并通过应用内通知告知您。

MacroAI Privacy Policy

Effective Date: September 3, 2026 | App Name: MacroAI (Windows / Android, Package: com.sowe.macroai)

1. Introduction

MacroAI ("the Software") respects and protects user privacy. This policy explains how the Software handles your information. By using the Software, you agree to this policy.

2. Information We Collect

The Software does not collect, upload, or share any personal data.

  • We do not collect personal information, usage habits, or operation records;
  • The Software contains no telemetry, analytics, or advertising SDKs;
  • Your scripts, image templates, node configurations, and user settings are stored only locally on your device and are never uploaded to any server;
  • Image matching (OpenCV template matching), OCR, and color detection all run offline on the device.

3. Network Access

Windows version

No network connections are established during operation. Updates are installed manually by downloading installers from our website or release pages.

Android version (Google Play channel)

This build contains no networking functionality and establishes no network connections. Updates are provided entirely by Google Play.

Android version (official website and other channels)

The App periodically sends an update-check request to our server (sowe.com). This request is used solely to determine whether a newer version exists; it carries none of your personal data, script content, or screen information.

4. Third-Party Services

The Software integrates no third-party analytics, advertising, or data-collection services. Its open-source components (including image processing and text recognition engines) run as local libraries and never communicate with external servers.

5. Android Permissions

MacroAI for Android uses the following system permissions. All permissions are used solely to implement automation features, never to collect personal information. All permissions are granted by you in system settings and may be revoked at any time; once revoked, related features stop working and no data processing remains:

  • Accessibility Service: used to perform automated taps, swipes, and other gestures, and to read on-screen elements; screen content is used only for on-device matching during script execution;
  • Screen Capture (MediaProjection): used only when scripts require image recognition, OCR, or color picking; captured content is processed temporarily in memory only and is never saved, uploaded, or shared with any third party;
  • Overlay (SYSTEM_ALERT_WINDOW): used to display the runner bubble, task panel, and node editor;
  • Foreground Service: used to keep automation tasks and the editor running reliably in the background.

6. Data Storage and Deletion

All data you create (scripts, template images, user settings) is stored in local directories on your device. We recommend backing up important data regularly; data security is governed by your own system security measures.

You may delete all local data at any time by uninstalling the App or clearing its data; we cannot remotely access, retain, or recover it.

7. Children's Privacy

The Software is not directed at children under 13, and we do not knowingly collect personal information from children.

8. Changes to This Policy

We may update this policy from time to time. Updates will be posted on this page with a revised effective date. If future versions introduce accounts, cloud services, or any data collection, we will update this policy and notify you in-app.

9. Contact

For questions or suggestions about this privacy policy, contact us at:

Email: macroai@sowe.com
