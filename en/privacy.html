Privacy Policy

Last updated: July 2026

1. Introduction

MacroAI (hereinafter referred to as 'the Software') respects and protects user privacy. This Privacy Policy explains how the Software collects, uses, and stores your information during operation. By using the Software, you agree to the terms of this Privacy Policy.

2. Information Collection

MacroAI is a locally-run macro automation tool (supporting both Windows and Android platforms). We solemnly commit that:

  • The Software does not collect any personal information, usage habits, or operation records;
  • The Software does not send any data to any server;
  • The Software does not contain any form of telemetry or statistical analysis;
  • All processing is performed entirely on your local device.

Scripts, images, configuration files, and other data you create during use are stored locally on your computer and are not uploaded to any remote server.

3. Network Access

The Software does not actively establish any network connections during operation. Version updates are performed by you proactively visiting the GitHub or Gitee release page to download the installer. The Software itself does not have automatic update or network communication capabilities.

4. Third-Party Services

The Software does not integrate any third-party analytics, advertising, or data collection services. Open-source components used by the Software run as local libraries and do not communicate with external servers.

5. Android Permissions

MacroAI for Android uses the following system permissions. All permissions are used solely to enable automation features and are never used to collect personal information:

  • Accessibility Service: Used to perform automated gestures such as taps and swipes, and to read UI element information;
  • Screen capture permission (MediaProjection): Used only when scripts require image recognition or OCR, to capture screen content for local analysis;
  • All captured screenshots are processed temporarily in memory only and are never saved, uploaded, or shared with any third party.

6. Data Storage and Security

All data generated while using the Software (including script configurations, template images, user configurations, etc.) is stored in local directories on your computer. We recommend regular backups of important data. Since all data is stored locally, data security is ensured by your own system security measures.

7. Children's Privacy

The Software is not directed at children under 13. We do not knowingly collect personal information from children.

8. Changes to This Privacy Policy

We may update this Privacy Policy from time to time. Updated versions will be posted on this page with an updated 'Last updated' date. If future versions introduce account systems, cloud services, or other features that require data collection, we will update this policy in a timely manner and notify you through in-app notifications.
