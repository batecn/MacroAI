Core Features

Powerful, Flexible

Visual recognition meets scripting — built for desktop automation

⚡

Visual Node Editor

Drag-and-drop workflow builder with 20+ node types, LOOP/CONDITION container nodes. Build automation flows without writing code.

👁

Image Recognition

OpenCV-based template matching with custom regions, adjustable thresholds, and multi-template matching for precise element targeting.

📝

OCR Text Recognition

Built-in OCR engine for text recognition in screen regions. Supports text comparison and conditional triggering.

🔍

Change Detection

Grid-based screen change detection, bar value tracking (HP bars, progress bars), with automatic periodic change filtering.

🔧

Lua Scripting Engine

Node operations auto-generate Lua code — approachable for non-programmers, extensible for developers.

🖥

Background Mode

Windows

Win32 PostMessage background input — no focus steal. Supports background screenshot & recognition for stealthy automation.

📐

Multi-Resolution Support

Independent design and runtime regions with automatic coordinate scaling. The same script runs stably across devices with different resolutions and scaling ratios.

🎁

Completely Free · No Ads

All core features are permanently free — no feature gating, no ad popups, no bundled adware.

🔄

Cross-Platform Scripts

The same Lua script runs on both Windows and Android. Share image templates across platforms — write once, run anywhere.
